# Publication-state snapshots

This directory contains small, versioned snapshots of the scientific state used
by publication-facing prose and figures. Full landscape and enrichment outputs
remain local under `output/`; selected compact reports/results are explicitly
unignored in `.gitignore`.

`c9_primary_analysis.json` is the canonical snapshot for the C9 ALS fingerprint
analysis.  It records the production design, cohort denominators, feature
attrition, empirical-Bayes prior degrees of freedom, bounded and unbounded
fixed-term outcomes, auxiliary-evidence ledger, explicit source paths, and the
permitted claim scope.

`c9_gsea_provenance.json` is the offline integrity receipt generated by
`scripts/snapshot_gsea_provenance.py`. It binds the retained bounded and
unbounded landscape inputs, all 24 robust GSEA tables, all six fixed-term
tables, and the current reference scripts to SHA-256 hashes while recomputing
the reported row counts and threshold patterns.

The two current auxiliary analyses have their own durable records:

- `c9_size_matched_null_inputs.json` freezes the HGNC map and term memberships
  consumed by `scripts/run_size_matched_null.py`; its compact results live at
  `output/size_matched_null.{json,csv,md}`.
- `c9_degree_stratified_null{,_terms}.json` and
  `c9_degree_stratified_null.md` record the fixed-scope pathway degree-matched
  sensitivity generated by `scripts/run_c9_degree_stratified_null.py`.

The snapshot is not a substitute for the full results.  When those local results
are available, `tests/test_publication_state.py` checks the snapshot against all
three bounded and three unbounded landscape files, fixed-term tables, robust
full-database summary counts, exact EB priors, and both auxiliary snapshots. The
same test guards selection wording and the withdrawn STRING/RNA/age boundary.
`tests/test_gsea_provenance.py` separately rebuilds and verifies the GSEA
integrity receipt from retained local artifacts.

Current primary state:

- `log2(x+1)`, Sex-adjusted empirical-Bayes moderated `|t|`;
- measured-only, undirected regulatory distance bounded at two hops;
- 3,264 measured features attempted (3,263 human UniProt rows plus iRT): 3,117
  valid gradients, 137 without a reachable measured neighbor, and 10 below the
  10-feature neighborhood guardrail;
- 1,407 valid anchors in the primary robust GSEA scope (`hop1 >= 20`);
- eightfold-threshold pattern `8/6/0` for C9-vs-Sporadic, C9-vs-Control, and
  Sporadic-vs-Control; unbounded sensitivity `6/0/0`;
- canonical graph-independent size-null `8/8/0` and separate robust-scope
  degree-matched sensitivity `7/7/0`.

The eight terms were discovered on this same cohort and fixed before method
transfer. The eightfold threshold is not a post-selection FWER/selective-
inference guarantee. STRING and matched RNA are withdrawn pending audited
reruns; age remains an unresolved legacy raw-scale proxy. Historical GSEA runs
did not embed the entire live CoGEx corpus, producer package revisions, or the
effective GSEA seed/default in the outputs, so local artifact integrity can be
checked but exact upstream regeneration is not yet guaranteed.

Update this snapshot only from a complete, identified analysis run. Keep its
associated narrative and visualization updates in the same reviewed commit
stack, and do not merge a partial stack that leaves those consumers stale.
